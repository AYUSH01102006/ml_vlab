Theoretical Background

Regression Models & Regularization

1. Linear Regression

Linear Regression models the relationship between an independent input variable x and a continuous target variable y using a straight line. It minimizes the sum of squared residuals (Ordinary Least Squares).

ŷ = w0 + w1x    |    Cost J(w) = (1 / N) ∑ (yi − ŷi)2

Limitation: When the underlying data follows a curve, a straight line has high bias and results in Underfitting.

2. Polynomial Regression

To capture non-linear curves, Polynomial Regression adds higher-order powers of the original feature (x2, x3, ..., xd) as new features and fits a linear model on those expanded features:

ŷ = w0 + w1x + w2x2 + w3x3 + ... + wdxd

Risk: If degree d is too large (e.g., d = 10), the curve wiggles wildly to pass through every training point, causing severe Overfitting (low Training MSE, very high Testing MSE).

3. Ridge Regression (L2 Regularization)

Ridge Regression prevents overfitting in high-degree polynomials by adding an L2 penalty term proportional to the square of the magnitude of coefficients (wj2). Controlled by hyperparameter λ (Lambda):

Cost JRidge(w) = (1 / N) ∑ (yi − ŷi)2 + λ ∑ wj2
  • When λ = 0: Ridge behaves identically to standard Polynomial Regression.
  • When λ > 0: Large weights are penalized, forcing the high-degree curve to become smooth and reducing Test Error.
  • When λ → ∞: All slope weights approach zero, flattening the curve towards the mean.

Quick Comparison Summary

Model Type Complexity Control Bias / Variance Typical Behavior on Curved Data
Linear Regression Fixed (d = 1) High Bias, Low Variance Underfits non-linear patterns
Polynomial (High d) Degree d Low Bias, High Variance Overfits noisy data points
Ridge Regression Degree d + Penalty λ Balanced Trade-off Good Fit via weight shrinkage

Step-by-Step Guide

Operating Procedure

1

Create or Upload a Dataset

In the Simulation tab, click directly anywhere on the graph canvas to plot custom data points (automatically split into Blue Training Points and Orange Testing Points). Alternatively, click "Load Sample Curve" or "Upload CSV" to load external real-world data.

2

Test Linear Regression (Underfitting)

Select Linear Regression. Observe the straight blue line and check the Train MSE, Test MSE, and Model Status Badge. Click "+ Add to Observation Table" to record the baseline reading.

3

Increase Polynomial Degree to Induce Overfitting

Switch to Polynomial Regression. Move the Degree (d) slider first to d = 3 (Good Fit) and then up to d = 10–12. Notice how the curve oscillates sharply to hit training points while Test MSE increases rapidly. Record both readings.

4

Apply Ridge Regression (λ) to Fix Overfitting

Keeping Degree high (d = 10 or 12), select Ridge Regression (or Compare All 3) and gradually increase the Penalty (λ) slider. Watch the jagged curve smooth out and the Test MSE drop!
